# Pizza Sales Analysis

This repository contains a pizza sales data analysis project based on pizza order records, product categories, sizes, and sales performance insights. The project includes a dataset, presentation/report assets, and screenshots that demonstrate the sales analysis workflow.

## Project Overview

The goal of this project is to analyze pizza sales performance and extract useful business insights such as total sales, category-wise performance, size-wise contribution, daily and monthly trends, and best-selling pizza types. It is designed for students, analysts, and beginners who want to understand sales reporting and dashboard-style data analysis.

## Dataset

The repository includes a compressed dataset file named pizza_sales.zip, which contains the pizza sales records used for the analysis. Additional project documentation and report assets are also included in the repository.

## Key Analysis Areas

The analysis can focus on the following business questions:

- Which pizza category contributes the highest sales?
- Which pizza size is most popular among customers?
- Which pizza type generates the highest revenue?
- What are the daily or monthly sales trends?
- Which pizza products have the highest and lowest average order values?

## Business Insights

This project is useful for understanding customer demand and product performance across categories and sizes. It can help in decisions related to inventory planning, product promotion, pricing, and menu optimization.

## Tools Used

- SQL for data queries and calculations
- Excel or Python for dataset preparation and analysis
- PowerPoint or PDF presentation for report summarization
- GitHub for project sharing and documentation

## How to Use

1. Download the repository.
2. Extract the pizza_sales.zip dataset.
3. Open the project report or dashboard screenshots for visual insights.
4. Use the dataset and report files to reproduce or extend the analysis.

To analyze pizza sales data and create a meaningful business report that highlights trends, product performance, category contribution, and customer demand patterns.
